# SPEC-002：Codex 本机文件只读访问

## 原因与范围

现有桥接禁用了 shell_tool，开发者提示词也禁止读取本机文件。启用只读文件工具，允许用户通过 IM 指定本机文件进行查看和分析；保持 read-only 沙箱、关闭命令网络访问，不自动批准写入、删除或提权。

默认工作目录改为项目目录，并支持通过 CODEX_WORKSPACE 配置。新线程和恢复的旧线程都应用相同权限配置，不更换既有线程映射，不改变模型、记忆、路由和发送行为。

## 验收与测试

- tests/test_codex.py：新建和恢复线程都启用 shell 工具、提示词允许读文件；每轮保持 readOnly 策略和 medium。
- 实际 Codex 调用读取临时测试文件中的随机标记，证明真实文件访问；同一会话再次读取更新内容验证 resume。
- 全量回归通过后更新独立状态索引。

本次不开放文件写入和删除，不为 API 聊天增加本地文件工具。
