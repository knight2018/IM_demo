# SPEC-003：桥接自检、网关解耦与 auto 快速路由

修正 SPEC-001 的纯命令远程执行和 SDK 导入耦合，不改历史 spec。

- /ping、/help 由桥接本地处理，模型配置命令继续由网关执行。自检只表示桥接在线，不表示模型上游可用。本地命令使用独立执行队列，避免网关请求占满工作线程后阻塞自检。
- 统一消息与发送协议不依赖飞书。分发器显式接收发送适配器；网关只执行处理器，不注入任何 IM 发送端。网关独立进程禁止导入 core.feishu、core.streaming、lark_oapi 时仍能启动并响应健康检查。
- auto 对完整匹配的寒暄、感谢、告别做本地判断，跳过分类 API，仅调用一次回答模型。含任务、指代和不确定的输入继续带上下文做原模型分类，不失败转移。
- 新增断网自检、线程占满自检、禁止 SDK 导入启动、本地快速路由、上下文保留及失败不切换回归。
- 最终全量回归通过才完成。
